### Git & Commit Tools

- git-commit-cn - Generate Chinese Git commit messages following Conventional Commits specification. Type prefix must be English, description must be Chinese. (source: custom)
- git-pre-push - Guard the full PR workflow chain. Blocks direct commits to protected branches, creates PRs automatically with three-level fallback before push, and enforces SDD mini-spec for large changes. (source: custom)
